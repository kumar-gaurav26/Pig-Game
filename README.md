# 🎲 Pig Game

A fun and interactive browser-based dice game built using HTML, CSS, and JavaScript. Pig Game is a two-player game where players compete to reach the winning score by rolling dice strategically while avoiding risky turns.

---

# 📌 Project Overview

Pig Game is a simple yet engaging web game designed to demonstrate core JavaScript concepts such as:

- DOM Manipulation
- Event Handling
- Game Logic Implementation
- Dynamic UI Updates
- State Management

The game provides a responsive and interactive gaming experience directly in the browser without requiring any external dependencies.

---

# 🎮 Game Rules

1. The game consists of **2 players**
2. Players take turns rolling a dice
3. Each dice roll adds to the player's **current score**
4. If the player rolls a **1**, the current score becomes **0** and the turn switches
5. Players can choose to **Hold** their score anytime
6. Holding adds the current score to the player's **total score**
7. The first player to reach the target score wins the game

# 🎯 Gameplay Workflow

```text id="krm9jq"
Start Game
    ↓
Player Rolls Dice
    ↓
If Dice ≠ 1
    → Add to Current Score
Else
    → Switch Player
    ↓
Player Holds Score
    ↓
Update Total Score
    ↓
Check Winner
    ↓
Continue Until Someone Wins
```
